3.Additional Info

 

 

3.1. Avoiding IP Conflicts

 

To prevent IP conflict issues, please verify if the allotted Default Gateway IP is currently not assigned to any existing PC in your office.

3.1.1How to Check for IP Conflicts

Before assigning your new Gateway IP, run these steps to ensure the address is vacant.

3.1.2 For Windows Systems

  1. Press the Windows Key, type cmd, and press Enter.
  2. In the black window, type: ping<space>[Your New GateWay iP]
  3. The Result: Windows will send 4 packets and stop.

○       If you get "Reply from..." : The IP is in use. Find the device and change its IP.

○       If you get "Request timed out" : The IP is likely clear.

3.1.3 For Ubuntu (Linux) Systems

  1. Press Ctrl + Alt + T to open the Terminal.
  2. Type the following command : ping<space>-c 4<space>[Your New GateWay iP]
  3. The Result:

○       If you see "64 bytes from...": The IP is active on the network.

○       If you see "Destination Host Unreachable" or 100% packet loss: The IP is vacant.

3.2. Disable Proxy Settings via Chrome

To ensure your new SDWAN connection works correctly, please follow these steps to disable any active proxy settings:

  1. Open Chrome Settings: Click the three vertical dots (⋮) in the top-right corner of Google Chrome and select Settings.
  2. Navigate to System: On the left-hand sidebar, click on System.
  3. Open Computer Proxy Settings: Click on Open your computer's proxy settings.

○       Windows users: This will open the Windows Proxy Settings window.

○       Ubuntu users: This will open the Network Proxy settings.

  1. Disable Proxy:

○       Set Automatically detect settings to OFF.

○       Set Use a proxy server to OFF.

  1. Save: Ensure you click Save or Apply before closing the window.

3.3. Tracing the path to gateway

Tracing the path to your gateway (or any IP address) is a classic networking move. It s the best way to see exactly where your data is lagging or dropping off.

 

3.3.1. Windows Command Prompt (CMD)

On Windows, the command is tracert. It s built-in and straightforward.

 

The Command:

tracert <space> Your New GateWay iP

 

Positive Results

Tracing route to Your Gateway Address

over a maximum of 30 hops

1 <1 ms <1 ms <1 ms Your Gateway Address

Trace complete.

3.3.2. Ubuntu Terminal

The Command:

traceroute <space> Your New GateWay iP

 

Positive Results

traceroute to Your Gateway Address, 30 hops max, 60 byte packets 1 _gateway (Your Gateway Address) 0.425 ms 0.398 ms 0.372 ms
