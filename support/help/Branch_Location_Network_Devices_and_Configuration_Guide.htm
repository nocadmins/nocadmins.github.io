BRANCH LOCATION NETWORK DEVICES

A simple reference for identifying branch network equipment and connecting it correctly

1. Introduction 

Know Your Network Devices

Branch locations use a set of network devices to provide internet connectivity, distribute the connection across the office, and allow staff to access treasury applications and other authorised resources

What each device does in our network




1. Fatpipe Router Device

The main branch SD-WAN device. It receives the internet links from the WAN modems and provides the network connection towards the branch LAN. 




2. WAN Modems

The modems terminate the ISP connections. 

* WAN 1 BSNL MPLS (10 Mbps)- FatPipe Port No.2
and 

*WAN 2 RailTel MPLS or BSNL VPNoFTTH (2Mbps Speed) - FatPipe Port no.3

provide the two internet links that connect to the Fatpipe device.

Note: Note: All administrators must identify and clearly label their office WAN connections and devices:

  • WAN 1: BSNL MPLS
  • WAN 2: RailTel or BSNL VPN

Refer to the "Treasury WAN 1 and WAN 2 ISP Details" table below to verify the respective ISPs and ensure all devices are properly labelled for easy identification and future reference.



3. LAN Main Switch and Distribution Switches (Juniper / D-Link)

The LAN Main Switch receives the LAN connection from Fatpipe. 


Distribution switches extend that connection to different sections, floors, or network points in the office.



4. Small Switches (D-Link)

Small access switches (with 6 ports) provide additional Ethernet ports near user areas, allowing multiple PCs to connect to the branch LAN.



5.Office  PCs

Office computers connect to the small switches or available access-switch ports. They use the branch network to access treasury applications and other permitted services.


 



6. Juniper Router

An existing Old Main router (instead of FatPipe Device) used by the treasuries. It is not currently used for SD-WAN but serves as a backup solution for SD-WAN connectivity.

3. Step-by-step cabling order

1.        WAN 1 Modem → Fatpipe Port 2 Connect the Ethernet/LAN output of the WAN 1 modem to the second port of the Fatpipe device.

2.        WAN 2 Modem → Fatpipe Port 3 Connect the Ethernet/LAN output of the WAN 2 modem to the third port of the Fatpipe device.

3.        Fatpipe Port 1 → LAN Main Switch Connect the first port of the Fatpipe device to the uplink/input port of the LAN Main Switch.

4.        LAN Main Switch → Distribution Switches Connect the LAN Main Switch to the required Juniper or D-Link distribution switches.

5.        Distribution Switches → Small D-Link Switches Connect distribution-switch ports to the small D-Link switches installed near user areas.

6.        Small Switches → PCs Connect each desktop PC to an available Ethernet port on the relevant small switch.

4. Important checks

·          Ensure that WAN 1 and WAN 2 are connected to the correct Fatpipe ports (Port 2 and Port 3 respectively).

·          The LAN connection to the switch network must come from Fatpipe Port 1.

·          Use suitable Ethernet cables and ensure that connectors are firmly seated.

·          After cabling, check link/activity indicators on the modem, Fatpipe, switches, and PCs.

·          Do not interchange WAN and LAN connections. If a branch has a different approved port mapping, follow the NOC/network administrator's instructions.

Note: This is a basic physical-connectivity guide. IP addressing, VLANs, routing, firewall policies, and ISP-specific settings should be configured as per the approved branch network configuration.
