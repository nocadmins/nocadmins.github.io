Treasury Network Support Portal

Welcome to the Treasury Network Support Portal. This portal provides information about Treasury branch network infrastructure, administrative responsibilities, technical guidelines and support services provided by the Treasury Network Operations Centre (NOC).

1. Treasury Network

Treasury branches are connected to the central network infrastructure through dedicated internet and private network connectivity. The infrastructure enables secure access to Treasury applications, government services and other authorised resources.

Network Infrastructure at Treasury Branches

The typical network infrastructure at a Treasury branch consists of the following devices:

1. FatPipe SD-WAN Router

Manages WAN connectivity and provides network traffic management, routing and failover between available network connections.

2. WAN Modems / ONUs

Provide connectivity from service providers. Branches generally have two ISP connections, depending on the available services.

3. LAN and Distribution Switches

Juniper and D-Link switches distribute network connectivity to different sections and systems within the Treasury office.

4. Access Switches

Smaller switches provide additional LAN connectivity for computers and other authorised network devices.

5. Desktop Computers

End-user systems connected to the LAN for accessing Treasury applications and authorised government services.

WAN Connectivity

Treasury branches generally use the following connectivity arrangements:

  • Primary WAN: BSNL MPLS connectivity, generally provisioned with 10 Mbps bandwidth.
  • Secondary WAN: BSNL VPN over FTTH at locations where the service is available. Other branches may have different secondary ISP arrangements.
  • SD-WAN: FatPipe manages available WAN links and supports connectivity failover based on the configured policies.
Important: All network devices, WAN connections and LAN cabling should remain properly connected and powered on. Any changes to network configuration or physical connectivity should be coordinated with the authorised Network Administrator and NOC team.

2. Treasury Admin / Network Admin and Their Duties

Effective network maintenance requires coordination between the Treasury Administrator, Network Administrator and the NOC team. Each role has specific responsibilities to ensure uninterrupted network services at the Treasury branch.

A. Treasury Administrator

The Treasury Administrator is responsible for coordinating branch-level administrative activities and ensuring that network-related issues are properly reported to the NOC.

  • Ensure that network devices, modems and switches are properly powered on and maintained.
  • Coordinate with the Network Administrator for network-related troubleshooting and maintenance.
  • Report internet connectivity interruptions and other network issues to the NOC promptly.
  • Provide accurate Treasury details, contact information and relevant technical information when reporting complaints.
  • Ensure that network devices are not switched off, disconnected or physically relocated without proper coordination.
  • Coordinate with the NOC and concerned service providers whenever ISP-related issues are reported.
  • Ensure that physical access to network racks and equipment is restricted to authorised personnel.
  • Inform the NOC in advance regarding office shifting, renovation or any activity that may affect network infrastructure.

B. Network Administrator

The Network Administrator is responsible for assisting with branch-level network infrastructure, physical connectivity and first-level technical troubleshooting in coordination with the NOC.

  • Monitor the operational status of FatPipe devices, WAN modems, LAN switches and other network equipment.
  • Check physical connectivity, LAN cables, power adapters and port status during network interruptions.
  • Assist in identifying whether a connectivity issue originates from the ISP, WAN modem, FatPipe device, switch or end-user computer.
  • Verify LAN connectivity and perform basic troubleshooting, including IP configuration and ping tests.
  • Coordinate with the NOC before making any changes to network configurations, device connections or routing arrangements.
  • Assist the NOC team during device installation, replacement, configuration and maintenance activities.
  • Maintain details of network devices, serial numbers, IP addresses, ISP connections and physical port connections.
  • Ensure proper cable identification and documentation of network connections.
  • Report faulty devices, abnormal LED indications and repeated connectivity interruptions to the NOC.
  • Assist in safely shutting down, relocating and reconnecting network equipment whenever required.
Coordination with NOC:

The Treasury Administrator and Network Administrator should coordinate with the NOC for technical assistance, configuration changes, device replacements and service restoration. Unauthorised configuration changes, factory resets or disconnection of network devices should be avoided.
